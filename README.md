# 🚓 ManhwPatrol

Бот-патруль активности чата. Считает сообщения, ведёт топы (день / неделя / месяц / всё время),
выдаёт звания, а каждый понедельник в 00:00 МСК начисляет топ-3 недели алмазы 💎 и крутки 💳
**прямо в ManhwCard**.

## Запуск за 5 шагов

1. **Создайте бота** в @BotFather → получите токен.
2. **Выключите Privacy Mode**: @BotFather → `/mybots` → ManhwPatrol → Bot Settings → Group Privacy → **Turn off**.
   Без этого бот не видит обычные сообщения в чате. (Если бот уже в чате — удалите и добавьте заново.)
3. **Заполните `config.py`**:
   - `BOT_TOKEN` — токен ManhwPatrol
   - `ADMIN_IDS` — ваши ID (те же, что в ManhwCard)
   - `MANHWCARD_DB_PATH` — путь к базе ManhwCard (тот же файл, что `DB_PATH` в config ManhwCard)
   - `MANHWCARD_BOT_TOKEN` — токен ManhwCard (необязательно: тогда победитель получит
     личное уведомление о награде от ManhwCard)
   - `MANHWCARD_USERNAME` — юзернейм ManhwCard без @
4. **Установите и запустите**:
   ```
   pip install -r requirements.txt
   python main.py
   ```
5. **Добавьте бота в чат** (с аккаунта админа — подсчёт включится сам) или напишите в чате `/track`.

Премиум-эмодзи: впишите ID в `emojis.py` — пока ID пустой, используется обычный эмодзи.

## Как считаются сообщения

| Засчитывается | Не засчитывается |
|---|---|
| Текст или подпись к медиа, где есть хотя бы 2 разных символа | Команды, пересланные сообщения, посты каналов, боты |
| Стикер / GIF / фото / голосовое — не чаще раза в 10 с | Тот же текст повторно подряд, «ааааа», «)))» |
| | Чаще раза в 3 с и больше 15 в минуту |

Все лимиты меняются командой `/setcd`.

## Награды

- Призы по умолчанию: 🥇 150💎+15💳 · 🥈 100💎+10💳 · 🥉 50💎+5💳 (меняются `/setprize`).
- Претендовать на приз можно от 100 сообщений за неделю (`/setmin`).
- Забаненные в ManhwCard (`/ban` из админ-панели ManhwCard) призы не получают — место переходит следующему.
- Если победитель ещё не запускал ManhwCard, награда ждёт его 30 дней: бот пробует выдать её
  каждые 10 минут, а игрок может нажать `/claim`.
- Каждая выплата пишется в таблицу `patrol_payouts` базы ManhwCard в одной транзакции с начислением —
  двойной выплаты не будет даже при перезапуске. Выплаты видны и в `/adminlog` ManhwCard.

## Импорт старой истории

Bot API не даёт ботам читать историю чата, поэтому подсчёт идёт с момента добавления бота.
Старую историю можно загрузить: Telegram Desktop → чат → ⋮ → «Экспорт истории чата» →
формат JSON, без медиа → прислать `result.json` боту в личку с подписью `/import`.
Учитываются только сообщения до старта подсчёта, с теми же правилами антиспама.
Ограничение Telegram — файл до 20 МБ.
