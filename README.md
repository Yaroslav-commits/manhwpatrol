# 🚓 ManhwPatrol

Бот-патруль активности чата. Считает сообщения, ведёт топы (день / неделя / месяц / всё время),
выдаёт звания и каждый понедельник в 00:00 МСК подводит итоги недели.

ManhwPatrol — **полностью отдельный бот**: свой репозиторий, свой проект на хостинге, своя база.
С ManhwCard он **никак не связан** — в ManhwCard ничего менять не нужно.
Награды топ-3 выдаёт админ вручную, а бот готовит для этого всё необходимое.

## Как проходит выдача наград

1. Понедельник 00:00 МСК — в чат уходит пост с итогами недели (и закрепляется).
2. Вам в личку приходит **ведомость**: победители, их ID и готовые команды ManhwCard:
   ```
   /give_diamond 123456789 150
   /give_attempts 123456789 15
   ```
   Нажатие на команду копирует её — вставляете в ManhwCard, и всё.
3. Жмёте «✅ Выдал» под ведомостью — победителю приходит поздравление от ManhwPatrol
   (если он хоть раз запускал бота), а в «Зале славы» награда отмечается выданной.
   «🚫» — отменить награду (например, если игрок накручивал).
4. Забыли выдать? Каждый день в 12:00 бот напомнит. Ведомость в любой момент — `/pending`.

## Запуск на bothost

1. Создайте бота в @BotFather → получите токен.
2. **Выключите Privacy Mode**: @BotFather → `/mybots` → бот → Bot Settings → Group Privacy → **Turn off**.
   Без этого бот не видит сообщения в чате. (Если бот уже в чате — удалите и добавьте заново.)
3. Загрузите эту папку в новый репозиторий, создайте на bothost новый проект (Python, запуск `main.py`).
4. Переменные окружения:

   | Переменная | Значение |
   |---|---|
   | `PATROL_BOT_TOKEN` | токен ManhwPatrol |
   | `MANHWCARD_USERNAME` | юзернейм ManhwCard без @ (если не `ManhwCardBot`) |
   | `PATROL_DB_PATH` | *(необязательно)* путь к базе в постоянной папке, если хостинг стирает файлы при обновлении |

   Админ (`6378471773`) уже вписан в `config.py`.
5. **Нажмите /start у ManhwPatrol в личке** — иначе бот не сможет прислать вам ведомость.
6. Добавьте бота в чат со своего аккаунта — подсчёт включится сам (или напишите в чате `/track`).
7. Проверка: `/pstatus` в личке бота.

Премиум-эмодзи: впишите ID в `emojis.py` — пока ID пустой, используется обычный эмодзи.

## Как считаются сообщения

| Засчитывается | Не засчитывается |
|---|---|
| Текст или подпись к медиа, где есть хотя бы 2 разных символа | Команды, пересланные сообщения, посты каналов, боты |
| Стикер / GIF / фото / голосовое — не чаще раза в 10 с | Тот же текст повторно подряд, «ааааа», «)))» |
| | Чаще раза в 3 с и больше 15 в минуту |

Все лимиты меняются командой `/setcd`.

## Призы

- По умолчанию: 🥇 150💎+15💳 · 🥈 100💎+10💳 · 🥉 50💎+5💳 (меняются `/setprize`, мест может быть до 10).
- Претендовать на приз можно от 100 сообщений за неделю (`/setmin`).
- Накрутчика можно убрать из топа и призов: `/exclude`.

## Импорт старой истории

Bot API не даёт ботам читать историю чата, поэтому подсчёт идёт с момента добавления бота.
Старую историю можно загрузить: Telegram Desktop → чат → ⋮ → «Экспорт истории чата» →
формат JSON, без медиа → прислать `result.json` боту в личку с подписью `/import`.
Учитываются только сообщения до старта подсчёта, с теми же правилами антиспама. Файл — до 20 МБ.
